# Research integrity, replication and publication checklist

This is a completed computational three-cell secondary analysis using previously public Real-POCQi human pairwise ratings and model answers alongside newly collected LLM-judge pairwise and rubric scores. The missing human absolute-rubric arm (cell D) and larger provenance factorial remain **proposals, not completed experiments or public preregistrations**. The archived protocol drafts should not be presented as prospectively registered plans for the executed analyses.

## Canonical files and claims

- Primary matched same-judge instrument effect, fixed-panel CIs, simultaneous CIs and Holm-adjusted p-values: `judge/out/robust_analysis.json`, generated by `judge/robust_analysis.py`.
- Source manuscript: `MANUSCRIPT.md`; figures `judge/out/existence_proof.png` and `judge/out/decomposition.png`.
- Judge results: `judge/out/grades.jsonl` and `judge/out/pairwise.jsonl`. Original data under `data/`; derived dataset under `dataset/`.
- Clinician-rubric files in `dataset/physician/` are study materials **without completed physician ratings**. No independent clinical gold standard was collected.

These check important calculations and design constraints, not every statistic's independence of the saved result tables. `SKIP_JUDGES=1 ./run_all.sh` recomputes archived-data analysis and fetches public data, requiring network access, but no paid judge rerun. A full `./run_all.sh` calls paid model APIs; LLM inference is not deterministic.

## PDF

`python3 build_pdf.py` renders the source manuscript with the Python Markdown package and local Chrome/Chromium. Override the browser location with `CHROME_PATH` when needed. The GitHub workflow builds a fresh PDF as a downloadable artifact; verify it visually against the text before submission. An older PDF in the repository is **not** evidence of synchronized manuscript content.

## Scientific boundaries

The completed study measures which system appears preferred under different evaluator instruments. It does **not** decide which system is clinically correct. The three observed cells do not identify a full human × instrument interaction. The human-vs-LLM contrast also differs in presentation/rendering and protocol. Four chosen AI judges do not provide a random sample of all possible judges. Porting these findings to the other study's private question distribution remains untested. Source-dataset licensing and attribution remain in force.
